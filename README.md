# snake-n-ladder
This is a python project. 
I have implemented the Snake and Ladder game logic using the Object oriented programming.

## key elements in SNAKE - LADDER game:
    -> players (name, position, status, rank etc)
    -> Dice (random number generation from 1 to 6)
    -> game Board (a dictionary was used to map snake and ladder positions)

### Separate Classes were used for each element :
  **Player, Dice, Board, and a Game class** that used all these classes to create, start and finish the game.
